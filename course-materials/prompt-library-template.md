# My Prompt Library

*Fill this in during Lab 4 (and keep adding to it). These are the prompts that did real work
this week — the reason the class outlasts the day. One card per prompt.*

**How to use a card:** copy the prompt, replace anything in `[BRACKETS]`, paste into Claude.

---

## The four parts of a working prompt (keep this at the top)

> **Context** — who you are, who it's for, what it's for ·
> **Task** — the one thing you want done ·
> **Format** — length, structure, tone ·
> **Example** — a line showing the style you want

A prompt with all four beats a one-liner every time, for free.

## Card 1 — Analyze a spreadsheet

```
WHEN I NEED:  to understand a data file fast

I PASTE / UPLOAD:  [the spreadsheet]

THE PROMPT:  Using the uploaded [file], and the analysis tool so the numbers are
             calculated not estimated: give me a quick orientation (date range,
             categories, totals), flag anything inconsistent or wrong, then tell me
             the [3] most important trends as one-sentence takeaways.

I CHECK:  the two biggest numbers myself, and whether any value looks 10x off
```

## Card 2 — Turn findings into an executive summary

```
WHEN I NEED:  a report from an analysis

THE PROMPT:  Write a one-page executive summary of [analysis] for [audience]. Structure:
             a one-sentence headline, "what's working" and "what needs attention", one
             recommendation with its main risk. Under [300] words. Flag any claim not
             directly supported by the data.

I CHECK:  that the headline is the right thing to lead with, and the flagged claims
```

## Card 3 — Retarget the same content for a new reader

```
WHEN I NEED:  the same content for a different audience

THE PROMPT:  Rewrite this for [new audience] instead of [old audience]. They care about
             [what they care about]. Keep it factual, make it useful to them, under [250]
             words.

I CHECK:  that it actually serves the new reader, not just swaps a label
```

## Card 4 — Report to slide outline

```
WHEN I NEED:  a deck from a report

THE PROMPT:  Turn this into a slide outline for a [5]-minute update to [audience]. One
             slide per key message, [5–6] slides. Each slide: a takeaway-style title and
             3 tight bullets. Start with the headline; end with the ask and its risk.
             Then add ~2 sentences of speaker notes per slide in a plain, first-person voice.

I CHECK:  that slide 1 lands the most important thing and it builds to the ask
```

## Card 5 — Edit, don't restart

```
WHEN I NEED:  to fix one thing in a draft

THE PROMPT:  [one surgical instruction — e.g. "tighten this section to three sentences and
             make the tone more direct"; "rewrite the recommendation as a specific action
             with an owner and deadline"; "cut every sentence a skeptic could call vague"]

I CHECK:  that it changed only what I asked
```
